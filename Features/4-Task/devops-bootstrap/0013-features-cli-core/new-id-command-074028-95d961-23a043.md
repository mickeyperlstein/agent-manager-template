## What
Implement the `features new-id [task|feature|epic]` command for generating collision-free 3-byte hex IDs.

## Scope
- Create `template_workflow/features/commands/new_id.py`
- Implement ID generation using `secrets.token_hex(3)`
- Implement collision detection by scanning all Features/ .md files
- Accept optional type argument (task|feature|epic) for logging context
- Print ID to stdout (for capture by agent)

## Acceptance Criteria
- [ ] `features new-id` prints 6-character hex string
- [ ] Generated ID is collision-free with all existing IDs in Features/
- [ ] Optional type argument accepted and logged
- [ ] Collision detection scans all .md files in Features/
- [ ] Max 10 retry attempts before giving up

## Test Conditions
- Run `features new-id` → verify 6-char hex output
- Run `features new-id task` → verify works with type arg
- Test collision: manually add ID to file, regenerate → verify different ID
- Verify no duplicates across multiple generations

## Definition of Done
- New-id command fully implemented
- All AC met
- Tests pass
