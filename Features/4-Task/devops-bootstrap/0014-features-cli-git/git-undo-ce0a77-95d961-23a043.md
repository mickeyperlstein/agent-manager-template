## What
Implement `features git undo` to revert the last Features/-scoped commit.

## Scope
- Create `commands/git/undo.py`
- Get files from last commit
- Validate all files are within Features/
- If not, reject undo with error (safety guard)
- Execute `git revert HEAD --no-edit`
- Print revert commit hash

## Acceptance Criteria
- [ ] `features git undo` reverts last commit
- [ ] Validates last commit only touches Features/ files
- [ ] Rejects undo if last commit has out-of-bounds files
- [ ] Uses `git revert` (not reset) — creates revert commit
- [ ] Prints revert commit hash

## Test Conditions
- Test with Features/-only last commit → reverts
- Test with out-of-bounds last commit → rejects with error
- Verify `git log` shows revert commit

## Definition of Done
- Undo command complete
- All AC met
- Tests pass
