## What
Implement `features git commit -m "<message>"` with out-of-bounds handling.

## Scope
- Create `commands/git/commit.py`
- Get staged files, validate all within Features/
- If out-of-bounds files found: log them, unstage, commit, re-stage
- Execute `git commit -m "<message>"`
- Print commit hash and summary

## Acceptance Criteria
- [ ] `features git commit -m "msg"` commits staged files
- [ ] Validates all staged files are within Features/
- [ ] Out-of-bounds files are logged, unstaged, and re-staged after commit
- [ ] Prints commit hash on success
- [ ] Handles errors gracefully

## Test Conditions
- Test with only Features/ files staged → commits
- Test with mixed files → logs out-of-bounds, commits Features-only, re-stages others
- Test with no Features/ files → error or no-op

## Definition of Done
- Commit command complete
- All AC met
- Tests pass
