## What
Implement `features git push` with scope validation.

## Scope
- Create `commands/git/push.py`
- Get files from last commit
- Validate all files are within Features/
- If not, reject push with error
- Execute `git push`
- Print push summary

## Acceptance Criteria
- [ ] `features git push` pushes current branch
- [ ] Validates last commit only touches Features/ files
- [ ] Rejects push if last commit has out-of-bounds files
- [ ] Prints push result
- [ ] Handles errors gracefully

## Test Conditions
- Test with Features/-only last commit → pushes
- Test with out-of-bounds last commit → rejects with error
- Verify error message lists violating files

## Definition of Done
- Push command complete
- All AC met
- Tests pass
