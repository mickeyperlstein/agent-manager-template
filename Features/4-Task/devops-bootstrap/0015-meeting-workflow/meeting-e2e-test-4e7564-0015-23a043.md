## Test 1: Default Meeting (happy path)

### Step 1.1 — Start a meeting
Open a **new Claude Code conversation** in this repo and type exactly:

```
/meeting architect pm
```

### What should happen:
- Agent reads `template_workflow/commands/meeting-protocol.md`
- Agent finds `template_workflow/agents/architect.md` and `template_workflow/agents/pm.md`
- Agent creates a temp file in `meetings/` folder
- Agent shows you a prefilled meeting file and asks you to fill in Topic, Goal, Agenda

### What to check:
- [ ] Agent found both agents without errors
- [ ] A meeting file preview was shown with `## Participants`, `## Topic`, `## Goal`, etc.
- [ ] You were asked to confirm/complete the meeting details

### Step 1.2 — Confirm the meeting
Type:

```
Topic: Testing the meeting workflow
Goal: Verify the meeting lifecycle works end to end
Agenda: 1. Introductions 2. Quick round-table 3. Wrap up
```

### What should happen:
- Agent saves the meeting file as `meetings/2026-04-07_testing-the-meeting-workflow.md`
- Agent deletes the temp file
- Agent adopts Architect role (MOD + Architect)
- Agent spawns PM as sub-agent
- Agent introduces participants and shows meeting commands

### What to check:
- [ ] Meeting file created in `meetings/` folder (check with `ls meetings/`)
- [ ] Introductions shown with labels (e.g., `MOD + ARCH`, `PM`)
- [ ] Meeting commands displayed (`/notes`, `/end-meeting`, etc.)

### Step 1.3 — Test routing
Type each of these one at a time:

```
PM: what do you think about the meeting workflow feature?
```

Then:

```

```

Then:

```

```

### What to check:
- [ ] First message: only PM responds
- [ ] Second message: both participants respond
- [ ] Third message: MOD responds directly, no sub-agent

### Step 1.4 — Check notes
Type:

```

```

### What to check:
- [ ] Current `## Notes` and `## Rolling Summary` are shown

### Step 1.5 — End the meeting
Type:

```

```

### What to check:
- [ ] Decisions, open questions, and action items displayed
- [ ] Meeting file updated with `## Decisions` content
- [ ] `## Rolling Summary` updated one final time

### Step 1.6 — Verify artifact


### What to check:
- [ ] File exists and has all sections filled in
