## Scope

Manual end-to-end test of the meeting workflow. Mickey runs through all three modes and verifies artifacts.

### Test Cases

1. **Default meeting:** `/meeting <agent1> <agent2>` — verify participant validation, meeting file creation, routing, closing with decisions
2. **Working meeting:** `/meeting --working <agent1> <agent2>` — verify prior-context capture, prefilled Relevant Info + Notes, then full lifecycle
3. **Resume:** `/meeting --resume` — verify meeting list with summaries, participant roster confirmation (add/remove), then resumed session
4. **Error case:** `/meeting <nonexistent-agent>` — verify agent-not-found handling

### Verify

- [ ] Meeting file created at `meetings/YYYY-MM-DD_<slug>.md`
- [ ] Participants section correctly populated
- [ ] Routing works (directed, broadcast, MOD)
- [ ] Notes and Rolling Summary updated during meeting
- [ ] `/end-meeting` produces Decisions and action items
- [ ] Working meeting prefills prior context correctly
- [ ] Resume shows summaries and allows participant changes
